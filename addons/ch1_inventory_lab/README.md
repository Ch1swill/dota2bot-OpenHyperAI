# Open Hyper AI Ch1 · 真人九格

独立本地自定义地图，引用当前安装的官方 `dota` 地图。仅真人的主英雄获得三个备用栏的使用权限和装备被动；BOT、幻象与分身保持原有物品栏规则。

2026-10-19 测试后用户发现普通对局的整套个人改键也变成默认，覆盖原因尚未确认。用户已于 2026-10-22 确认手动恢复整套改键，完整的个人配置已备份。后续 BOT 战斗验证使用独立后台服务器，个人配置保持原样，自动启动入口仍停用。进一步真人客户端测试前必须备份完整的个人按键文件和配置，不能把仅有默认键位的文件当成恢复备份。

安装（仓库根目录 PowerShell）：

```powershell
./tools/install-nine-slot-addon.ps1 -DotaRoot 'D:\steam\steamapps\common\dota 2 beta'
```

使用原来的 DOTA2 启动入口，在主菜单控制台输入：

```text
dota_launch_custom_game ch1_inventory_lab dota
```

进入队伍界面，选择阵营，点击“锁定并开始”，再选择英雄。空位自动填充 BOT；开局准备时间为 90 秒。普通 BOT 房间仍使用“本地开发脚本”；九格需要从自定义地图入口进入。

当前修订在地图初始化时注册引擎原生 `dota_turbo_game_mode`，默认采用加速规则，同时保留九格所需的自定义地图客户端脚本环境。后台对照原生 Turbo，已确认信使速度 1100、中路一塔生命 1800/护甲 12，以及固定赏金野怪的双倍金币。真人客户端的选中/跟随行为需要单独验证。

独立测试安装不会覆盖现用 `ch1_inventory_lab`：

```powershell
./tools/install-nine-slot-addon.ps1 -DotaRoot 'D:\steam\steamapps\common\dota 2 beta' -TestOnly
```

然后从原 Steam 入口启动 DOTA2，在主菜单控制台输入：

```text
dota_launch_custom_game ch1_inventory_turbo_test dota
```

测试版与现用版共用源码，但目录和启动命令独立。测试完成前不要用不带 `-TestOnly` 的安装命令更新现用版。安装器不启动游戏、不修改个人配置或 Steam 启动项。

九格地图对双方 BOT 的主英雄明确设置“疯狂”AI（引擎难度 4），独立于 FretBots 的奖励倍率；真人不受影响。英雄尚未出生时会等待，替换英雄后会重新设置，同一英雄不会每帧重设。

双方 BOT 英雄初始化时先清空原有控制玩家列表，再只加入各自电脑玩家，避免追加所有者后仍遗留真人权限。服务器还会拒绝真人向 BOT 所属英雄、信使、召唤物下达移动或施法命令；查看技能和物品不受影响。真人自己的英雄、信使、召唤物及真人之间的正常共享操作保持可用。此更新需要新开九格对局，现有对局不会自动重新初始化。

2026-10-22 修正了以下问题：

- 夜魇 BOT 不行动：BOT 公共库会永久缓存填充前的空夜魇队员名单，导致分路/角色判断报错。现在每次读取当前名单，保留普通房间的真人 ID 修正规则。更新 BOT 时需同步本仓库的 `bots/FunLib/aba_global_overrides.lua`。
- 开局出现双倍等强化符：启用引擎的当前官方神符刷新规则，替换自定义地图默认的旧规则。后台实测开局四个赏金符、2/4 分钟水符、6 分钟首次强化符；刷新时点交给当前安装版本的引擎处理。
- 所有人没有信使：在英雄出生前启用官方个人免费信使模式。后台实测已生成十只信使，并观察到双方攻击、补刀和英雄交战。

安装器默认只部署 `game/dota_addons/ch1_inventory_lab`；`-TestOnly` 则只部署独立的 `ch1_inventory_turbo_test`，并在覆盖前备份对应版本。BOT 公共库的修复需要一并同步至现有 BOT 安装；本轮维护已单独备份并更新该文件。地图安装器不修改个人配置或 Steam 启动项。Lua modifier 只由本地图初始化，不能从普通 BOT 的 FretBots 入口加载。

备用栏使用引擎原生主动施法权限，并补充装备原生 intrinsic modifier；装备自身的不叠加、冷却、禁用等规则继续适用。新物品或具有特殊脚本的物品仍需逐个兼容验证。
